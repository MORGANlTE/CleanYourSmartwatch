# Security

Experimental AI-generated software; no security audit has been completed. Please report vulnerabilities privately using the repository's GitHub **Security → Report a vulnerability** feature if enabled. Otherwise ask the maintainer to enable private reporting without posting exploit details or personal watch data in an issue. No maintainer email is embedded in this template.

Include version, synthetic reproduction, expected/actual safety behavior, and impact. Never send pairing keys/codes, serials, eSIM data, local addresses, raw backups or health data. Local state is not signed; keep the directory private and do not accept journals/plans from strangers. Avoid running the toolkit while another process modifies package state.
